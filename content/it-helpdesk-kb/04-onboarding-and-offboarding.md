# Onboarding & Offboarding — Cobalt Dynamics IT Helpdesk

*Invented content for a student project.*

## New hire IT checklist (Day 1)
1. CD-SSO account created by IT before start date (manager triggers this via the HR system).
2. Laptop and standard hardware collected from the office IT cage, or couriered for remote hires.
3. Enrol MFA on first login.
4. Complete the mandatory "Security Basics" training module (30 minutes) within the first week.
5. Request access to team-specific tools via the Access Request Portal (manager approval required).

## Common Day 1 issues
- Can't log in yet: account provisioning can lag HR by a few hours on a new hire's actual start
  day — check with your manager before logging a ticket.
- Software Catalogue looks empty: catalogue entries are role-based; if you don't see an expected
  tool, your role tag may not be set yet — ticket under "Account & Access".

## Offboarding checklist (last day)
1. Manager submits an offboarding ticket at least 2 business days before the last day.
2. IT disables CD-SSO and revokes all access at end of business on the last day (not before,
   unless HR flags an urgent/security offboarding).
3. All Cobalt Dynamics hardware must be returned (see `02-hardware-and-equipment.md`).
4. Email and file access are retained read-only for the manager for 30 days, then archived.

## Urgent/security offboarding
- If HR or Security flags an offboarding as urgent, IT disables access immediately on request,
  without waiting for the standard 2-day notice.
